原因：本技能只做审查（diagnose），不做生成（generate）。生成向文件会诱导模型越界去改代码、
立 token、装 Tailwind，而这与技能定位冲突。审查确实需要的那部分（评级、检查表、
症状反查、暗色等扩展）都已本地化，所以离线也能完整审一遍。

为什么不翻译
------------
规则档是「引用证据」。保留英文原文才能被溯源、被 diff，也不会在转述中失真。
中文只出现在本技能自写的 SKILL.md 与 references/android/ 两处，
两者分工是「方法」与「证据」，责任边界清楚。

如何更新
--------
    TMP=$(mktemp -d)
    git clone --depth 1 https://github.com/edisonmbli/refactoring-ui-skill "$TMP/ui"
    diff -ru "$TMP/ui/skills/refactoring-ui/references" <技能目录>/references
看完 diff 再按需覆盖，并把本文件顶部的提交号改成新 sha。

注意：上游 `15-beyond-the-book.md` 里每一条都标了「书里没有这条」，
引用时不要把它当成原书规则。
