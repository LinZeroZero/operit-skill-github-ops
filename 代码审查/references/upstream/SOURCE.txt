为什么不逐篇改写
----------------
规则档是「引用证据」，不是「我写的结论」。原文保留才能：
  1. 与本技能自研的 Android/Operit 三档区分责任边界；
  2. 日后用 git diff 对比上游更新（见下）；
  3. 避免改写过程中引入失真——审查结论要能被追溯。

如何更新
--------
    TMP=$(mktemp -d)
    git clone --depth 1 https://github.com/awesome-skills/code-review-skill "$TMP/cr"
    diff -ru "$TMP/cr/reference" <技能目录>/references/upstream
看完 diff 再按需覆盖，并把本文件顶部的提交号改成新 sha。
